Подключение SMS.RU

Только для владельца ZapFormat. Регистрация покупателей будет подтверждаться звонком за 40 копеек по тарифу SMS.RU.

Скопируйте api_id из раздела «Главная» на уже открытой вкладке SMS.RU и вставьте сюда.

Ключ передаётся напрямую вашему серверу по HTTPS. В сайт и GitHub он не записывается. Не отправляйте ключ в переписку.
