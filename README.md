# Parts AI

Рабочий прототип магазина автозапчастей.

Сейчас в репозитории только живая GitHub Pages-версия:
- AI-first приветственная страница;
- поиск по артикулу, VIN и свободному запросу;
- мобильная выдача точных позиций и аналогов;
- корзина;
- гараж;
- заказы;
- история браузера и свайп назад.

Серверная интеграция и реальные данные подключаются отдельно через backend.
