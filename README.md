# Parts AI

Рабочий каркас интернет-магазина автозапчастей.

## Уже реализовано
- адаптивная главная;
- поиск по артикулу / VIN / текстовому запросу;
- результаты с ценой, сроком и остатком;
- локальная корзина;
- гараж;
- заказы;
- профиль;
- mock-провайдер PartGrade;
- серверный слой для будущего API PartGrade;
- наценка на закупочную цену;
- PWA manifest.

## Архитектура
Клиент → Next.js → наш backend → PartGrade API

PartGrade-доступы хранятся только на сервере. Клиент видит только нашу конечную цену.

## Запуск
```bash
npm install
npm run dev
```

## Следующий шаг
После получения доступа PartGrade заменить mock-провайдер в `lib/partgrade` на реальный API.
