# ZapFormat

ZAPFORMAT — интернет-магазин автозапчастей.

## Текущее состояние

Frontend:
- минималистичная AI-first главная;
- профессиональная плотная выдача по артикулам и аналогам;
- корзина с перепроверкой цены/наличия в интерфейсе;
- мобильная нижняя навигация;
- личный кабинет;
- детальная страница заказа с позиционными статусами, шкалой движения, повтором заказа и возвратом;
- экраны регистрации и входа.

Backend:
- Node.js API в `backend/`;
- PostgreSQL-схема пользователей, сессий, машин, корзин, заказов, позиций, возвратов и уведомлений;
- регистрация, вход, выход, текущая сессия;
- HttpOnly-сессии;
- профиль пользователя;
- шаблоны systemd/nginx для Timeweb Cloud.

Публичный frontend пока работает через GitHub Pages. Реальные данные поставщика и его ключи должны использоваться только на backend.
